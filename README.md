# 整理HQ（SeiriHQApp）

プロンプト交通整理と、画像・動画素材の交通整理を1つにしたAndroidアプリ。

- プロンプト：①固定 + ②個別切替 + ③任意入力 → 完成プロンプトをワンタップコピー
- 素材：取り込み → Inbox → 状態・タグ・プロジェクト付与 → 検索
- プロジェクトは両機能の共通単位
- 素材はパスコード必須、指紋認証は任意。権限がなければ閲覧と取り込みのみ
- 削除はゴミ箱経由。保存先はアプリ内または選んだフォルダ、期限切れは自動で完全削除
- ダウンロード整理：apkやzipなどの不要ファイルをフォルダから直接削除
- 交通整理モード：未整理の素材を1件ずつスワイプで仕分け
- プロンプトでコピーした内容を、取り込んだ素材の生成元として記録
- フォルダ指定での一括取り込みと、選んだ素材のZIP書き出し
- 素材の画像をコピーして、生成AIアプリのプロンプトに直接貼り付け

仕様は docs/SPEC.md、開発の続きは docs/HANDOFF.md を参照。
